# PLSC 508 Fall 2026 — presentation sign-ups

Two separate sign-ups:

- **[METHODS.md](METHODS.md)** — Methods Tutorial sign-up sheet
- **[READINGS.md](READINGS.md)** — Application Reading Review sign-up sheet
